# Archive

This directory contains deprecated, historical, or superseded materials that are retained for reference and reproducibility purposes.

Archived content may include:

* Deprecated workflow versions
* Experimental prototypes
* Obsolete folder structures
* Early pilot datasets
* Draft materials no longer used in active studies

Files stored in this directory are not considered part of the active research program unless explicitly referenced by a study.

## Purpose

The archive supports:

* Research traceability
* Historical reference
* Reproducibility of prior experiments
* Preservation of development history

Current research activities are maintained under:

```text
research/
```

Please refer to the relevant study directory for the latest workflows, datasets, manuscripts, and results.
